# Настройка скиллов HQ

Orca+ сама ставит скиллы HQ в `~/.claude/skills` и обновляет их с каждой версией. Этот скилл
доводит их до рабочего состояния у конкретного человека. Людям ничего не отправляет. Каждый шаг —
по одному вопросу, всё необязательное — только после «да».

## 1. Папка HQ

`python3 "${CLAUDE_SKILL_DIR}/hq_location.py"` печатает путь. «Папка HQ не задана» → в Orca+
Настройки → HQ Folder. Папки ещё нет — её создаёт плагин Strata HQ (`/strata-hq:init`), потом путь
вписать в настройку. Orca+ сама кладёт указатель в `~/.config/orca-plus/hq.json`, его читают скрипты
скиллов.

## 2. Сводка «кого ждём» — `<HQ>/config/waiting-digest.json`

Спроси, куда слать сводку команде, и собери файл (Write):

```json
{
  "team_channel": "C…",
  "team_channel_name": "#team",
  "team_departments": ["IT"],
  "owner_slack_id": "U…",
  "clickup_team_id": "…",
  "slack_workspace_url": "https://<workspace>.slack.com"
}
```

- `owner_slack_id` — сам владелец (Slack MCP `slack_search_users` по почте; покажи найденного и спроси
  «это ты?»). `team_channel` — `slack_search_channels` по названию.
- `team_departments` — отделы из `orca pulse person show` (поле роли после «·»), кто идёт в канал;
  остальные получают личку.
- `clickup_team_id` — id воркспейса ClickUp (из ссылки `app.clickup.com/<id>/…`).

## 3. Фоновые задачи

`python3 "${CLAUDE_SKILL_DIR}/schedule.py" status` — что стоит. Предложи по одной, с тем, что она делает:

| Задача          | Что делает                                                                                   | Нужно                            |
| --------------- | -------------------------------------------------------------------------------------------- | -------------------------------- |
| `commit-review` | в 18:30 Codex смотрит новые коммиты дня по проекту разом; P0–P2 → отчёт в Reports           | Codex CLI с входом               |
| `tone-rollup`   | раз в день сворачивает твои правки черновиков в `wiki/tone.md`                               | разведчик Slack или ответы из HQ |
| `triage-rollup` | раз в день сворачивает твои решения по разбору ClickUp в `triage/<проект>.md`                | разбор ClickUp в HQ              |

После «да»: `schedule.py install <задача> --dry-run` (показать), затем без `--dry-run`. Убрать —
`schedule.py remove <задача>`. На macOS задачи ставятся в launchd, на Linux — в crontab пользователя;
на Windows скрипт откажет (задачи — bash), так и скажи. Перед `commit-review` один раз `python3 ~/.claude/skills/hq-commit-review/review.py baseline`,
чтобы Codex не тратил лимит на старые коммиты.

## 4. Автоматизации Orca+

Готовые расписания. Сначала `orca-plus automations list` — что уже есть, дубли не заводить. Каждую
создавай после «да» с `--disabled`, покажи, включи по подтверждению (`orca-plus automations edit <id> --enabled`).
Папка запуска — HQ: `--repo path:<HQ>`. Модель — `--extra-agent-args="--model sonnet"`.

| Имя                  | Расписание (`--trigger`, `--timezone` пользователя) | Промпт                                                                                                                                                                                                                                                                                                                  |
| -------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Итоги дня            | `30 19 * * *`                                       | Итоги дня по скиллу daily-review: собери журнал за сегодня, напиши HQ/daily/<сегодня>.md, мне — коротко с номерами предложений. Ничего не применяй и никому не пиши, пока я не отвечу номерами.                                                                                                                         |
| Итоги месяца         | `0 18 1 * *`                                        | Итоги месяца по скиллу daily-review, раздел «Месяц»: прошлый месяц из HQ/daily и недельных отчётов, напиши HQ/improvements/<YYYY-MM>.md, мне — коротко с номерами. Ничего не применяй и никому не пиши, пока я не отвечу номерами.                                                                                      |
| Неделя: что улучшить | `FREQ=WEEKLY;BYDAY=SU;BYHOUR=18;BYMINUTE=0`         | Недельный разбор по скиллу weekly-improve: собери неделю, напиши отчёт в HQ/improvements/, мне — только пункты, где нужно моё решение, с номерами. Ничего не применяй и никому не пиши, пока я не отвечу номерами.                                                                                                      |
| Кого ждём 18:00      | `0 18 * * 1-5`                                      | Вечерняя сводка «кого ждём» по скиллу hq-waiting-digest: собери открытые ожидания, проверь, что каждое ещё живо, команде — одним сообщением в канал с тегами, остальным — в личку. Отправляй только через карточку Approve; ожидания сам не закрывай и новых не записывай. Мне в итоге — что ушло и что похоже закрыто. |
| Садовник             | `FREQ=DAILY;BYHOUR=4;BYMINUTE=0`                    | Ночной садовник HQ: выполни /strata-hq:garden. Проекты из реестра только читаешь, никому ничего не пишешь; коммит — только в HQ, без push. В конце — коротко: что изменил sync и какие находки новые.                                                                                                                   |

`--missed-run-grace-minutes 720` — если Mac спал, запуск догонит после пробуждения.

## 5. Итог

Одной строкой: что включено, чего не хватает (папка HQ, Codex, Slack) и что с этим сделать.

## Нельзя

- Отправлять что-либо людям; включать задачи и автоматизации без «да».
- Трогать скиллы в `~/.claude/skills`, которые Orca+ не ставила (нет файла `.orca-plus-skill.json`).
