# Заметка в HQ → Notes без повторов

Notes в HQ — это ожидания Pulse (`orca pulse wait …`). Хранилище само не даёт добавить заметку, почти дословно повторяющую открытую. Ловить «то же самое другими словами» — твоя часть: «Иван должен настроить вебхук» и «жду от Ивана вебхук» — одна заметка.

## 1. Разбери фразу

- **Кто** — человек, о котором заметка (Иван, Катя…). Нет человека — простая заметка.
- **В какую сторону:**
  - человек должен что-то сделать, мы ждём от него → `on-them`;
  - человек ждёт чего-то от владельца → `on-me`;
  - без человека → простая заметка (`--source note`, `--direction on-me`).
- **Что** — коротко, своими словами, без «сохрани в заметку». Номер задачи, если он есть.
- **Срок** — «до пятницы», «20.10» → ISO-дата для `--due`. Нет срока — без `--due`.

## 2. Найди похожую открытую

```bash
orca pulse wait list --person "<имя>" --json      # заметки об этом человеке
orca pulse wait list --json                       # простые заметки: смотри те, где personId пустой
```

Сравнивай по смыслу, а не по словам: тот же человек и то же дело — это одна заметка, даже если слова другие. Разные задачи у одного человека — разные заметки. Закрытые (`resolved`, `cancelled`) не считаются: если Ивану снова что-то нужно, это новая заметка.

## 3. Реши

| Нашлась открытая… | Делай |
|---|---|
| о том же, ничего нового | ничего не добавляй |
| о том же, но новый срок или деталь | `orca pulse wait update <id> [--due <дата\|none>] [--detail "<текст>"] [--title "<текст>"]` |
| не нашлась | `orca pulse wait add --direction <on-them\|on-me> --person "<имя>" --title "<что>" [--due <дата>] [--project <slug>]` |

`--project` — только если заметка явно про текущий проект (slug из `registry.yaml` папки HQ: `python3 ~/.claude/skills/hq-setup/hq_location.py`).

Если `wait add` ответил «Already open, not added again», значит хранилище само нашло повтор. Не добавляй с `--force` — скажи владельцу, что заметка уже есть. `--force` только если он прямо сказал «всё равно добавь».

## 4. Ответ владельцу — одна строка

- «Записал: Иван — настроить вебхук, до пт.»
- «Уже есть заметка от 15.10: „Иван — вебхук“ — не дублирую.»
- «Обновил заметку от 15.10: срок теперь пт.»

Не пиши в «Done for you», не логируй решение (`pulse decision log`) и ничего не отправляй людям — это только заметка для владельца.
